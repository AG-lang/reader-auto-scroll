# 阅读助手：自动下翻

Chrome 扩展，适合中键滚轮不可用的阅读页面。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。

## 使用

- **开始/暂停扩展自动滚动**：
  - 点击右下角控制条的“开始滚动”按钮。
  - 按键盘快捷键 `S`（输入框内不会触发）。
- **鼠标中键原生漫游**：
  - 按鼠标中键即可正常唤出 Chrome **原生滚轮漫游圆盘指针**（即使在设置了 `overflow: hidden` 或防复制的小说网站上也能正常唤起）。
  - 中键点击超链接保留原生“在新标签页打开”行为。
- **速度调节**：
  - 拖动速度条，或点击“加速”/“减速”按钮。
  - 按快捷键 `Alt+上方向键` / `Alt+下方向键`，每次增减 1 px/s。
- **控制条折叠与显隐**：
  - 点击 `×` 将控制条收起为右下角小按钮，再次点击即可展开。
  - 按 `Alt+Shift+R` 或 `F8` 可完全隐藏/显示控制条。
